右クリックメニューに追加

PF File searchをエクスプローラの右クリックメニューに追加します。

既に設定がされている場合、メニューにチェックマークが付いています。

このメニューを実行するには、Windows Vista以降等では、PF File searchを管理者権限で起動する必要があります。

pffs.exe又はpffs.exeへのショートカットを右クリックし、[管理者として実行]をクリックして下さい。

このコンピュータへの変更を許可しますか？

と表示されるので、宜しければ[はい]をクリックする事で管理者権限で起動します。

右クリックメニューに追加すると、エクスプローラでドライブ／フォルダ／フォルダの何も無い場所で右クリックをすると[PFFSで検索]と言うメニューが表示され、クリックすると、該当のドライブ／フォルダを探す場所として起動します。

[右クリックメニューに追加]はレジストリにデータを書き込みます。

PF File searchが不要になった場合、レジストリを削除する為に、もう一度上記作業を実行して、PF File searchをもう一度起動し、[右クリックメニューに追加]にチェックが入っていない事を確認して下さい。

参考

PF File searchがレジストリを書き込む場所

HKEY_CLASSES_ROOT\Directory\shell\findWithPFFS
HKEY_CLASSES_ROOT\Directory\Background\shell\findWithPFFS
HKEY_CLASSES_ROOT\Drive\shell\findWithPFFS
HKEY_CLASSES_ROOT\.pffs
HKEY_CLASSES_ROOT\pffs_auto_file
