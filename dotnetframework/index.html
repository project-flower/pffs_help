.NET Frameworkについて

PF File searchの実行には、Microsoft .NET Framework 4.0/4.0 Client Profile以上のインストールが必要です。

.NET Framework（ドットネット フレームワーク）とは、Windowsアプリケーションの実行／開発プラットフォームの一つで、Windows Vistaには3.0、Windows 7には3.5.1、Windows 8には4.5が含まれています。

インストールされているかどうかは、[コントロール パネル]→[プログラムと機能]の一覧から確認出来ます（Windows 7の場合）。

インストールするには、Windows Update（オプション）を使用するか、Microsoft .NET ホームからダウンロードして下さい。

Client Profileはクライアント アプリケーションで使用される機能のみを抽出した軽量のセットアップ パッケージです。

.NET Frameworkの開発者向け機能が不要な場合、Client ProfileでもPF File searchが実行出来ます。
