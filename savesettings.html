検索条件を保存

現在の検索条件をファイルに保存します。

ファイルは .pffs と言う拡張子で保存されます。

保存された検索条件ファイルを開くには、コマンドラインの第1引数に指定する、pffs.exeもしくはPF File searchのウィンドウにドラッグ＆ドロップする事で開く事が出来ますが、右クリックメニューに追加を行う事で同時にファイルの関連付けも行われ、.pffsファイルをダブルクリックする事でPF File searchを起動する事が出来る様になります。

Version 1.6以前で保存された検索条件ファイルは、Version 2.0以降ではサイズの指定が読み込まれないのでご注意下さい。
